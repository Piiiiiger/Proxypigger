3x-ui 可以驱动一个 Telegram 机器人，用于监控、告警、备份和远程管理。
管理员拥有完全的控制权；普通用户（通过 Telegram ID 关联）则可以
查询自己的用量和链接。

<Callout type="info">
  想获取最新动态和社区支持？欢迎加入官方 Telegram 频道
  [@XrayUI](https://t.me/XrayUI)。它与下文中那个由你自行运行、用于管理自己面板的
  机器人是两回事。
</Callout>

## 完成配置

<Steps>

<Step>
### 创建机器人

向 [@BotFather](https://t.me/BotFather) 发送消息，发送 `/newbot`，然后复制**机器人令牌**（bot token）。
</Step>

<Step>
### 查找你的 Telegram ID

获取你的数字 Telegram 用户 ID（机器人连接成功后，其自带的 `/id` 命令会显示该 ID）。
这就是你的**管理员** ID。
</Step>

<Step>
### 配置面板

在面板设置中启用 Telegram 机器人，并填写**令牌**和**管理员聊天 ID**
（多个时以逗号分隔）。保存后，再向你的机器人发送消息。
</Step>

</Steps>

## 命令

所有人的命令菜单里是账号命令；每位管理员自己的对话里是管理命令。所有功能也都可以
通过按钮使用，账号菜单和管理菜单都是中文。

| 命令             | 适用对象 | 作用                                                         |
| ---------------- | -------- | ------------------------------------------------------------ |
| `/start`         | 任何人   | 管理员打开管理菜单，已绑定的用户打开账号菜单，其他人看到绑定方法；`/start <激活码>` 直接绑定激活码对应的账号 |
| `/report`        | 用户     | 用量：剩余流量、今日用量、下次清零、到期时间、在线 IP        |
| `/ips`           | 用户     | 当前在线的 IP（中转服务器从不出现）以及正在生效的封禁和剩余时间 |
| `/daily`         | 用户     | 日报设置；也可以用 `/daily on`、`/daily off`、`/daily 21:30`（北京时间） |
| `/bind <激活码>` | 任何人   | 用激活码绑定；直接发送激活码也可以                           |
| `/help`          | 任何人   | 使用帮助                                                     |
| `/users`         | 管理员   | 全部用户，每页十个，带状态、IP 名额和到期时间                |
| `/user <名字>`   | 管理员   | 按名字的一部分查找用户；只有一个结果时直接打开用户卡片       |

`/status`、`/id`、`/usage <arg>`、`/inbound <remark>` 和 `/restart` 的用法不变。

### 绑定账号

用户是指绑定了客户端的 Telegram 账号。在用户页面点 **我的激活码** →
**一键绑定 Telegram**，会带着账号的激活码打开机器人，按「开始」即可绑定；也可以把
激活码直接发给机器人，大小写和横线都不影响。一个激活码只能把一个账号绑定到一个
Telegram 账号，每个 Telegram 账号每小时可尝试五次。绑定会写入客户端所在的每个入站，
保存入站不会让绑定丢失。

### 账号菜单

已绑定用户的 `/start` 会显示账号状态、以进度条表示的剩余流量、到期时间和剩余天数、
在线 IP，以及正在生效的封禁或违规次数，并提供用量详情、在线设备、日报设置、封禁记录
（最近 90 天，含时间和原因）和帮助按钮；帮助里也列出了使用规则。点按钮会在原消息上切换；
通知下面的按钮则会发一条新消息，原来的日报或提醒会保留。

### 管理菜单

管理员的 `/start` 会统计在线用户、需要续期、已到期、流量用尽和已停用的用户，
以及正在生效的 IP 封禁和在线节点。从 **用户列表** 和 **需要续期**（7 天内到期、
一个月内已到期，或流量用了九成以上）可以打开用户卡片：套餐、用量、到期时间、
在线 IP 和封禁。在卡片上管理员可以：

- **续期** —— 增加 7 天，或按日历增加 1、3、6 个月或 1 年，默认同时清零已用流量（可取消
  勾选），与用户页面的续期相同。按月续到下个月的同一天（北京时间），没有这一天就到月底，
  到期日是 31 号的用户之后还会回到 31 号。按周期售卖的套餐只提供它的月数。确认页会显示
  续期前后的到期时间，连按两次也只续期一次。
- **清零流量** —— 在所有服务器上清零用量；因流量用尽被停用的用户会恢复。
- **停用 / 启用** —— 作用于该用户所在的每个入站。
- **解封 IP** —— 解除 IP 限制的封禁。
- **解除封禁** —— 解除防滥用封禁；解除停用时同时清除违规次数。
- **清除违规** —— 清除违规次数；封禁记录保留并标记为已清除。
- **封禁记录** —— 该用户最近 90 天的封禁。

**更多工具** 会打开原有的全部管理按钮：服务器用量、按流量排序的报告、备份、
封禁日志、入站、在线客户端、添加客户端向导、群发等。

## 报告与告警

- **周期性报告** —— 按 `tgRunTime` 计划（默认 `@daily`），机器人会向管理员
  发送服务器用量（主机、版本、运行时长、负载、内存、在线客户端、流量）、
  一份已耗尽/即将到期的客户端列表，以及——如果启用了 `tgBotBackup`——
  一份数据库 + Xray 配置的备份。通过 Telegram ID 关联的客户端则会收到
  各自的到期/配额提醒。
- **账号通知** —— 机器人每分钟检查一次已绑定的用户，在各自的日报时间（默认北京时间
  20:00）发送每日用量（如已开启），并在到期前 7、3、1 天发送续费提醒。IP 限制封禁某个
  用户的 IP 时，会通知该用户和管理员，管理员的消息里带有解封按钮。管理员还会在探针中
  某台服务器到期前 7、3、1 天收到续费提醒。
- **防滥用通知** —— [防滥用](/docs/operations/security)封禁或停用账号时，会把原因、第几次
  违规和剩余时间告诉用户和管理员；管理员的消息带有解除封禁和查看用户的按钮。规则设为提醒时，
  同一用户每小时最多提醒一次。只记录的检测中，端口扫描和网络攻击立即通知管理员（同一用户同一
  规则每小时最多一次），其余汇总在每天北京时间 09:00 的日报里。同一网络注册很多账号时，会连同
  账号列表通知管理员。
- **事件告警** —— 由 `tgEnabledEvents` 选定（默认 `login.attempt,cpu.high`）：

  | 事件            | 触发时机                                                |
  | --------------- | ------------------------------------------------------- |
  | `login.attempt` | 面板登录成功或失败时（附带 IP 和用户名）                |
  | `cpu.high`      | CPU 超过 `tgCpu` 百分比（默认 80）                      |
  | `memory.high`   | 内存超过 `tgMemory` 百分比（默认 80）                   |
  | `xray.crash`    | Xray-core 崩溃                                          |
  | `outbound.down` / `outbound.up` | 某个出站断开 / 恢复                      |
  | `node.down` / `node.up`         | 某个节点下线 / 重新上线                  |

提醒的提前时间由 `expireDiff`（到期前的天数）和 `trafficDiff`
（剩余配额的 GB 数）决定；两者默认均为 `0`（关闭）。

## 设置

| 设置项         | 默认值                     | 含义                                           |
| -------------- | -------------------------- | ---------------------------------------------- |
| `tgBotEnable`  | `false`                    | 总开关。                                       |
| `tgBotToken`   | _（机密）_                 | 机器人 API 令牌。                              |
| `tgBotChatId`  | _（无）_                   | 以逗号分隔的**管理员** Telegram ID。           |
| `tgBotProxy`   | _（无）_                   | `socks5://`、`http://` 或 `https://` 代理。    |
| `tgBotAPIServer` | _（默认）_              | 自定义 Telegram Bot API 服务器。               |
| `tgRunTime`    | `@daily`                   | 报告计划（cron / `@daily` / `@every …`）。     |
| `tgBotBackup`  | `false`                    | 在周期性报告中附带一份数据库备份。             |
| `tgCpu` / `tgMemory` | `80` / `80`          | CPU / 内存告警阈值（百分比）。                 |
| `tgLang`       | `en-US`                    | 原有管理工具的语言；账号菜单和管理菜单固定为中文。 |
| `tgEnabledEvents` | `login.attempt,cpu.high`| 投递哪些事件。                                 |

<Callout type="warn">
  机器人令牌掌控着你的机器人——务必妥善保密，且只添加**可信的**管理员聊天 ID。
  登录告警绝不会包含密码。
</Callout>

<Callout type="info">
  如果你更倾向于通过邮件接收告警，邮件（SMTP）通知会镜像同样的这些事件
  （`smtpEnabledEvents`）——请在面板设置中配置 SMTP。
</Callout>
